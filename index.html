Monthly files & settings

Update bidding data

Normal update: select only the latest View All FO Bids export, then tap Analyse. Your saved line PDF and Bid List exclusions will be reused.

New bidding month or first import on this device: select all three files. The PDF and monthly Bid List must be replaced together.

Files are processed on this device and are not sent to a server. Internet is needed to load spreadsheet/PDF libraries.

After a successful import, the parsed bidding data and results are saved only in this browser on this device. Each pilot must import the files once on their own device; they are not shared automatically.

Advanced: manually adjust FO capacities

If PDF extraction misses a line, enter overrides such as F49=2, one per row.

Privacy and limitations

No login credentials required. No crew data is bundled with this app. Bid report formats can vary; review the import status and validate results against actual awards. Data is saved in this browser using IndexedDB until you clear it or the browser removes site storage. It is not synced between devices. On shared devices, others using this browser can access the saved crew data.
